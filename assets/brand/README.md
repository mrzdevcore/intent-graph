# ig brand

Thin-line owl. Say "ig" as *eye-gee*.

| File | Use |
|---|---|
| `lockup.svg`, `lockup-dark.svg` | Owl plus wordmark, for light and dark backgrounds (README header) |
| `owl.svg`, `owl-dark.svg` | The owl alone, light and dark backgrounds |
| `owl-watching.svg`, `owl-planning.svg`, `owl-approved.svg`, `owl-flagging.svg` | State variants (watching is the viewer header mark) |
| `icon.svg` | App icon |
| `favicon.svg`, `favicon-16.svg` | Favicon (the first follows `prefers-color-scheme`); inlined in `viewer/index.html` |

Colours: accent gold `#E8A317` (dark `#F0BD4F`), flagging red `#E03131`, ink `#14161A`, light `#F3F4F6`.

Wordmark: light monospace "ig" (JetBrains Mono 300, falls back to the system monospace). It is live text, not outlined; outline it before any public print use.
